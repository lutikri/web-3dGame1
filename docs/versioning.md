# Версия игры

Единственный источник версии — `src/config/GameVersion.js`, константа `GAME_VERSION`.
Она отображается в главном меню, на стартовом экране загрузки и в первоначальной настройке.
Старая надпись `2.3.4` была статическим элементом интерфейса; новая отслеживаемая нумерация начинается с `0.1.0`.

## Когда менять

Версию меняем перед публикацией сборки или после завершения заметного этапа разработки.
Не повышаем её при каждом коммите: несколько коммитов могут составлять одну версию.
Для идентификации отдельного коммита используем его Git hash.

Формат — `MAJOR.MINOR.PATCH`:

- `0.1.1` — исправления и небольшие доработки текущей сборки.
- `0.2.0` — следующий заметный этап: новый уровень, механика или крупное изменение игрового процесса. PATCH сбрасывается в ноль.
- `1.0.0` — первый полноценный релиз. До него используем `0.x.y`.

## Как менять

1. Изменить строку `export const GAME_VERSION = "0.1.0";` в `src/config/GameVersion.js` на следующий номер.
2. Включить это изменение в коммит завершённого этапа или подготовки сборки. Надписи в интерфейсе обновятся автоматически.
3. При выпуске сборки можно поставить Git tag, например `git tag v0.1.0`, на соответствующий коммит.

`APP_BUILD_REVISION` и параметры импорта `?v=...` служат для сброса кеша модулей при выпуске сборки.
Это отдельный технический механизм, а не отображаемая версия игры.
`npm run stamp-modules -- <revision>` выполняется только при явной подготовке релиза или развёртывании;
обычное изменение версии не требует запуска этого скрипта.
