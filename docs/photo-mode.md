# Photo mode через консоль

## Снимок по F9

После загрузки игры нажать **F9**: браузер скачает PNG текущего 3D-кадра.
Ширина и высота снимка составляют 200% текущего физического рендера:
например, из 1920×1080 получается 3840×2160. Число пикселей увеличивается в четыре раза.
Временно используется максимальное MSAA, поддерживаемое GPU.
Текущие текстуры, эффекты, фильтрация mip0, камера и настройки photo mode сохраняются.
Обычное разрешение и сглаживание восстанавливаются сразу после копирования кадра, до кодирования PNG.
HTML-интерфейс, меню и отладочные панели в картинку не входят.
Повторные нажатия во время кодирования не запускают дополнительные загрузки.
Если размер снимка превышает ограничения GPU, команда сообщает ошибку в консоли.

Та же команда из консоли:

```js
await operatorGameDebug.downloadScreenshot();
```

## Настройки photo mode

Открыть консоль браузера (F12 → Console) после загрузки игры.

```js
await operatorGameDebug.setPhotoMode(true);
operatorGameDebug.getPhotoMode();
operatorGameDebug.setPhotoMode(false);
```

Режим временно включает стандартный профиль Ultra, MSAA 8× (в пределах поддержки GPU),
GTAO max и первый уровень bloom в полном разрешении, а также существующие shadow maps max (2048).
Меньшие уровни пирамиды bloom сохраняются для широкого размытия. Flares используют его полный первый уровень.
Рендер использует физическое разрешение окна: CSS-размер × `devicePixelRatio`,
без бюджета пикселей профиля, ручного render scale и адаптивного снижения разрешения.
После включения команда ждёт загрузки полных вариантов текстур панели и интерьерных материалов,
даже если обычная очередь была отключена профилем Low.
Текстуры материалов используют максимальную поддерживаемую анизотропию.

Отключение возвращает предыдущие настройки рендера, постобработки и фильтрации текстур.
Полные текстуры остаются загруженными; возврат к preview-текстурам не выполняется.
Настройки photo mode не сохраняются. Выбор обычного профиля качества отключает режим.
Режим не останавливает симуляцию, не меняет камеру и не скрывает HUD.

## Принудительный mip0

```js
await operatorGameDebug.setPhotoMode(true, { mip0: true });
```

Для текстур материалов (включая KTX2) используется `LinearFilter` без mipmap-фильтрации:
при обычной выборке материал использует базовый уровень текстуры. Анизотропия в этом варианте — 1.
Сами mipmaps не удаляются. Вернуть обычную фильтрацию можно повторным включением без опции или отключением режима.
Mip0 может усилить рябь и мерцание на удалённых или наклонных поверхностях, поэтому по умолчанию выключен.
Render targets, environment maps и data textures этим переключателем не изменяются.
Новые текстуры и изменения DPI подхватываются, пока режим включён.

## Тени и экспериментальные эффекты

Максимальное качество применяется к существующим источникам, настроенным с `castShadow`.
Лампы, обслуживаемые `PointLightPoolRuntime`, сейчас используют слоты без теней;
photo mode не добавляет им shadow maps и не снимает ограничения числа слотов света.
Тени от всех таких ламп требуют отдельного изменения системы освещения.
Экспериментальные SSGI, SSR и screen-space shadows не включаются автоматически:
они используют другой путь постобработки и не являются частью стандартного Ultra.
