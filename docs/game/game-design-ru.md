# OperatorGame — геймдизайн

> Статус: основной живой документ продукта.
>
> Этот файл определяет опыт игрока, progression, flow смен, обучение и текущие границы проекта.
>
> При конфликте механических правил реактора использовать `fusion-core.md`.
>
> Для структуры кода использовать `../project-structure.md`.

## Фантазия игрока

Игрок — сменный оператор старой промышленной термоядерной установки Terragen Systems.

Он не строит реактор и не управляет комплексом сверху. Он находится внутри физического объекта, читает аналоговые приборы, сигнальные лампы, служебные экраны, звук и поведение помещений.

Основная задача игрока — провести назначенную смену, обеспечить требуемую мощность и сохранить установку в рабочем состоянии.

Игра строится вокруг ощущения первого рабочего дня на объекте:

* игрок получает назначение;
* прибывает во входную часть комплекса;
* читает Shift Brief на служебном терминале;
* находит нужное рабочее помещение;
* выполняет смену;
* физически покидает рабочую зону;
* получает отчёт;
* получает новые назначения.

## Текущий игровой маршрут

```text
Первый вход на сайт
-> Setup Wizard
-> Terragen / TGlobal First Boot
-> Main Menu
-> Assigned Shifts
-> загрузка смены
-> Entrance Corridor
-> Entrance Area
-> Control Booth
-> трёхминутная смена
-> возврат в Entrance Area
-> выходная дверь
-> Shift Report
-> Assigned Shifts
```

Игровой сцены лифта нет.

Переезд на объект через personnel transfer lift показывается как короткая загрузочная презентация между меню и уровнем. Это не отдельная управляемая сцена.

## 1. Первый запуск: Setup Wizard

При первом входе на сайт игрок проходит обязательную первичную настройку.

Setup Wizard содержит:

1. выбор языка;
2. выбор графического пресета;
3. настройку гаммы;
4. подтверждение настроек.

После завершения настройки параметры сохраняются локально. Перед первым входом в главное меню запускается одноразовая 20–40-секундная презентация Terragen / TGlobal: краткий контекст компании, Site-12 и роли нового оператора.

First Boot использует несколько атмосферных кадров и минимум текста. Он должен работать как развлечение и worldbuilding, а не как длинная экспозиция. После первого просмотра презентация не повторяется автоматически и остаётся доступной через `ARCHIVE` служебного терминала.

При следующих запусках Setup Wizard не показывается. Все параметры остаются доступны через Settings.

## 2. Главное меню

Главное меню содержит основные пункты:

* `PLAY`;
* `SETTINGS`;
* дополнительные служебные пункты по необходимости.

Нажатие `PLAY` открывает экран `ASSIGNED SHIFTS`.

Фоном главного меню служит жилая зона персонала / personal accommodation. Это атмосферная menu scene, а не доступный для исследования Staff Room и не новая gameplay-система.

## 3. Assigned Shifts

Экран выбора смен представляет собой не обычный выбор уровней, а корпоративный список назначений оператора.

### Компоновка

Слева расположены три карточки смен.

Справа расположена область подробностей выбранного назначения.

Пока смена не выбрана, справа отображается:

```text
- NOTHING SELECTED -
```

Кнопка `START SHIFT` неактивна.

### Начальное состояние

При первом запуске доступна только первая карточка:

```text
TERRAGEN SYSTEMS
APPLICATION APPROVED

FIRST OPERATOR
QUALIFICATION SHIFT

ASSIGNED
```

Остальные две карточки показывают:

```text
- NOT ASSIGNED -
```

Они неактивны и не открывают подробности.

### Выбор квалификационной смены

После выбора первой карточки справа появляется краткое назначение:

```text
FIRST OPERATOR QUALIFICATION SHIFT

Your application has been approved.

Operational inst
Report to the assigned Terragen Systems facility entrance and complete the operator qualification procedure.
ructions will be provided on site.
```

После выбора назначенной смены кнопка `START SHIFT` становится активной.

Текст может упоминать personnel transfer lift, но не должен обещать отдельную игровую сцену лифта.

Нажатие `START SHIFT` запускает загрузку уровня.

Первая загрузка Qualification показывает 2–3 простых instructional frames о чтении реакторной панели и завершается короткой имитацией спуска personnel transfer lift к Site-12. Обычные загрузки смен вместо First Boot используют короткие Site-12 slides, схемы систем, safety notices и фрагменты Archive.

## 4. Entrance Corridor

Игрок появляется в простом длинном входном коридоре.

Позади игрока находится закрытая bulkhead door, которая позднее используется как физический выход со смены.

Впереди находится service door, ведущая в Entrance Area.

Окружение:

* несколько тусклых промышленных ламп;
* бетонные и металлические поверхности;
* местами видимая порода или грубо обработанная стена;
* служебные надписи;
* ощущение перехода между транспортной частью объекта и внутренним пропускным пунктом.

### Начальное обучение

После появления игрок получает короткие неблокирующие подсказки.

Первая подсказка:

```text
W A S D — MOVE
```

Она исчезает после того, как игрок начинает двигаться.

Вторая подсказка:

```text
MOUSE — LOOK
```

Она исчезает после достаточного движения камеры.

При наведении на service door появляется:

```text
LMB — INTERACT
```

Наратор в Entrance Corridor ещё не начинает основной брифинг. Игрок сначала самостоятельно входит во внутреннюю часть объекта.

## 5. Entrance Area

После открытия service door игрок попадает во входную зону комплекса.

В помещении находятся:

* старый рабочий стол;
* старый физический служебный терминал;
* General Announcement System или служебное радио;
* сигнальная лампа;
* указатели на `CONTROL BOOTH`;
* двери в будущие помещения;
* обозначение текущего уровня допуска;
* выход обратно в Entrance Corridor.

После входа в Entrance Area включается General Announcement System.

Содержание сообщения зависит от выбранной смены:

* квалификационная смена;
* проверка неисправных приборов;
* испытание топливной смеси.

Наратор сообщает назначение смены и указывает, что рабочий бриф доступен на служебном терминале.

Пример структуры сообщения:

```text
Your assigned shift is ready.

Review the Shift Brief on the entrance terminal.

Proceed to Reactor Control Booth RCB-02 when prepared.
```

Наратор объясняет назначение и контекст, но не сообщает решение реакторной задачи.

## 6. Служебный терминал

На старом физическом моноблоке Site-12 работает новый Terragen software. Игрок взаимодействует с терминалом в мире и получает компактный diegetic-интерфейс.

Первая версия терминала содержит только:

* `SHIFT BRIEF`;
* `SYSTEMS`;
* `HELP`;
* `ARCHIVE`.

Терминал не имитирует полноценную Windows, файловую систему или набор декоративных приложений.

Страница `SHIFT BRIEF` содержит:

* название смены;
* профиль испытания;
* основную задачу;
* известные особенности;
* условия успешного завершения;
* служебные предупреждения.

Экран выбора смены содержит только краткое назначение. Реальные операционные инструкции находятся на терминале и являются частью игрового мира.

Терминал показывает только активное назначение выбранной смены. Неактивные смены не должны выглядеть доступными. Первый просмотр обязательной страницы `SHIFT BRIEF` создаёт событие готовности смены.

`SYSTEMS` кратко описывает доступные системы объекта. `HELP` хранит управление и уже открытые обучающие подсказки. `ARCHIVE` принимает документы, лор и повтор First Boot без влияния на progression.

После закрытия терминала игрок проходит по указателям в Control Booth.

## 7. Навигация по комплексу

Путь от Entrance Area до Control Booth должен быть коротким и понятным без плавающего quest marker.

Навигация строится через:

* настенные указатели;
* подписи над дверями;
* цветовые полосы;
* освещение;
* видимость Control Booth в конце маршрута.

За закрытыми дверями могут находиться будущие зоны:

* `POWER BUS`;
* `PUMP STATION`;
* `STAFF ROOM`;
* другие служебные сектора.

На текущем этапе эти помещения могут быть пустыми или отсутствовать за дверями.

Двери должны восприниматься как намеренно закрытые:

```text
ACCESS RESTRICTED
QUALIFICATION INCOMPLETE
```

или:

```text
LOCAL AUTHORIZATION REQUIRED
```

Плейсхолдерные комнаты не являются частью текущей игровой задачи.

## 8. Control Booth Tutorial

Подробный туториал панели используется только во время первой квалификационной смены.

Когда игрок подходит к панели:

```text
HOLD RMB — LEAN TO PANEL
```

После успешного наклона:

```text
HOVER A CONTROL
```

После наведения на регулятор:

```text
MOUSE WHEEL — ADJUST
```

После первой регулировки системные подсказки прекращаются.

Герой думает:

```text
I think I need to start it.
```

Игрок должен самостоятельно найти кнопку `IGNITE` по надписи и расположению на панели.

Кнопка не должна подсвечиваться отдельной стрелкой или готовым quest marker.

Подсказка `SPACE — say apple` не используется в текущем flow.

## 9. Каналы обучения

Обучение разделено на три независимых канала.

### Tutorial Hints

Короткие системные подсказки управления:

* `W A S D`;
* `MOUSE`;
* `LMB`;
* `RMB`;
* `MOUSE WHEEL`.

Они показывают только способ управления и исчезают после выполнения действия.

### Operator Thoughts

Короткие мысли главного героя.

Они описывают наблюдаемый симптом или намерение:

* `I think I need to start it.`
* `Too hot.`
* `The output is still too low.`
* `The reaction went out.`
* `It is responding again.`

Мысли не дают точной последовательности действий.

### Narrator / General Announcement System

Наратор сообщает:

* назначение смены;
* контекст испытания;
* требование открыть `SHIFT BRIEF` на служебном терминале;
* результат смены;
* необходимость покинуть рабочую зону.

Наратор не сообщает, какие точные значения нужно выставить на регуляторах.

## 10. Основной цикл реактора

После нажатия `IGNITE` начинается трёхминутная реакторная последовательность.

Игрок управляет:

* `Fuel Injection`;
* `Magnetic Field`;
* `Coolant Flow`;
* аварийным `Vent / Purge`;
* связанными кнопками запуска и диагностики.

Игрок должен:

1. запустить реакцию;
2. следовать меняющемуся `Grid Demand`;
3. сохранять приемлемую температуру;
4. поддерживать containment;
5. избегать накопления критического Core Stress;
6. реагировать на особенности выбранной смены;
7. завершить 180-секундную последовательность.

Для Qualification одного выживания недостаточно. Игра накапливает продолжительность соответствия output текущему demand, время в warning/critical состояниях, stalls, safety events и качество прохождения ramps. Зачёт требует осознанного управления Field, Fuel и Coolant на протяжении смены.

Точные правила реактора определены в `fusion-core.md`.

## 11. Завершение смены

После окончания 180 секунд реактор автоматически переводится в безопасное состояние.

Смена имеет три основных исхода.

### Qualification Passed

Установка пережила смену, а игрок обеспечивал приемлемое соответствие demand, прошёл ramps и не находился слишком долго в warning/critical состояниях.

Наратор сообщает, что квалификация успешно завершена, и просит покинуть рабочую зону.

### Insufficient Output

Установка сохранилась, но игрок систематически не обеспечивал требуемую мощность.

Наратор сообщает, что принципы управления не были освоены и квалификация не засчитана.

Игроку сразу доступен `RESTART SHIFT`.

### Safety Trip

Автоматическая защита остановила установку из-за критического состояния, потери реакции или превышения безопасных ограничений.

Наратор сообщает, что сработала защита, и просит покинуть рабочую зону.

Игроку сразу доступен `RESTART SHIFT`.

### Повтор Qualification

После провала быстрый restart полностью сбрасывает реактор, incidents, objectives, report recorder и состояние комнаты, но не повторяет First Boot, длинную загрузочную презентацию, уже прочитанный терминальный brief и обязательное ожидание ранее прослушанного VO.

Tutorial остаётся event-driven: реплика объясняет один принцип, затем система ждёт действие. При повторе краткие подсказки показываются только для ещё не выполненных шагов либо открываются через `HELP`. После успешной Qualification для перепрохождений становится доступен `SKIP TRAINING`.

При любом исходе игрок не переносится в меню автоматически.

Он должен физически покинуть Control Booth и вернуться в Entrance Area.

## 12. Физический выход

После завершения смены игрок проходит обратно через тот же маршрут.

По пути могут измениться отдельные элементы окружения:

* часть ламп переходит в дежурный режим;
* меняется цвет сигнала;
* выключается шум реактора;
* включается служебное сообщение;
* на выходе загорается разрешающий индикатор.

Игрок возвращается в Entrance Corridor и взаимодействует с ручкой bulkhead door.

Именно это действие завершает уровень.

После взаимодействия экран затемняется и открывается Shift Report.

## 13. Shift Report

Shift Report не должен быть таблицей из большого количества технических чисел.

Сверху отображается основной результат:

```text
QUALIFICATION PASSED
```

или:

```text
RETRY REQUIRED
```

Ниже показываются три главных показателя.

### Grid Compliance

Показывает, насколько хорошо фактическая мощность соответствовала `Grid Demand`.

Основное значение — процент времени, проведённого внутри допустимого диапазона мощности.

Пример:

```text
GRID COMPLIANCE
82%
ACCEPTABLE
```

### Operating Efficiency

Показывает общее качество сочетания топлива, поля, температуры и полезной мощности.

Пример:

```text
OPERATING EFFICIENCY
74%
STABLE
```

### Peak Core Stress

Показывает худшее состояние установки во время смены.

Пример:

```text
PEAK CORE STRESS
46%
CONTROLLED
```

или:

```text
PEAK CORE STRESS
100%
SAFETY TRIP
```

Под показателями может находиться одна короткая служебная строка:

```text
No major safety intervention recorded.
```

или:

```text
Automatic protection system activated.
```

Дополнительные подробные данные могут существовать во внутренней отладке, но не должны перегружать основной экран результатов.

## 14. Прогрессия

### До успешной квалификации

В меню доступна только:

* `First Operator Qualification Shift`.

Две остальные карточки остаются:

```text
- NOT ASSIGNED -
```

При `Insufficient Output` или `Safety Trip` новые смены не открываются.

Квалификационная смена остаётся назначенной для повторной попытки.

### После успешной квалификации

После возвращения в Assigned Shifts две пустые карточки заменяются на:

* `Instrument Reliability Check`;
* `Cost of Running Trial`.

Обе смены становятся доступными одновременно и могут быть пройдены в любом порядке.

## 15. Instrument Reliability Check

Вторая смена использует тот же маршрут:

```text
Entrance Corridor
-> Entrance Area
-> Service Terminal
-> Control Booth
-> Shift
-> Return
-> Shift Report
```

Наратор предупреждает о возможных проблемах с оборудованием.

Особенности:

* стрелки могут запаздывать, дрожать или залипать;
* лампы могут давать неправильный сигнал;
* Self-Test показывает симптомы, но не сообщает готовое решение;
* игрок сверяет несколько источников информации;
* true simulation state остаётся отдельным от displayed instrument state.
* локальное ухудшение освещения делает фонарик необходимым рабочим инструментом, а не необязательным предметом.

Цель смены — научить игрока диагностировать состояние по нескольким независимым симптомам.

Подробный панельный туториал повторно не показывается.

## 16. Cost of Running Trial

Смена использует тот же маршрут и Control Booth.

Terragen Systems испытывает более дешёвые топливные смеси.

Особенности:

* изменённое соотношение топлива, тепла и мощности;
* краткие провалы подачи;
* нестабильный output;
* повышенный риск перегрева или stall;
* необходимость учитывать долгосрочную эффективность, а не только текущую мощность.

Подробный панельный туториал повторно не показывается.

## 17. Observation Port

Observation Port выполняется после того, как три смены проходят end-to-end, но до финального polish.

Он даёт дополнительный физический источник информации:

* `EFFICIENCY / STALL / STRESS`;
* `OUTPUT / DEMAND / BATTERY`;
* `PUMPS / COOLANT / FUEL`;
* `VIEWPORT SHUTTER`;
* `ALARM SILENCE`.

`ALARM SILENCE` подтверждает или приглушает разрешённые звуковые alarms, но не скрывает визуальные предупреждения и не отменяет критическое состояние. Observation Port не заменяет основную панель и не должен становиться обязательным для понимания базового reactor loop.

## 18. Текущая граница проекта

Завершённая первая версия игры состоит из:

* Setup Wizard;
* Main Menu;
* Assigned Shifts;
* одноразовый Terragen / TGlobal First Boot;
* отдельную короткую загрузочную презентацию Site-12;
* Entrance Corridor;
* Entrance Area;
* служебный терминал с `SHIFT BRIEF / SYSTEMS / HELP / ARCHIVE`;
* Control Booth;
* First Operator Qualification Shift;
* Instrument Reliability Check;
* Cost of Running Trial;
* Shift Report;
* progression между тремя сменами;
* настоящий pause и базовые in-game settings.

Эта версия должна быть полностью законченной и понятной без Power Bus, Pump Station, Staff Room и playable elevator.
