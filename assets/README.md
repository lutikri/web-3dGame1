# Runtime assets

Files in this directory are loaded by the browser build.

Do not put heavy source files here. Use `asset-source/` or `3dGameAssetsDev/` for editable originals.

```text
mesh/environment/    Level architecture GLBs
mesh/panel/          Operator panel GLBs
mesh/prefabs/        Reusable prefab GLBs
runtime-textures/    Compressed KTX2/HDR runtime textures
sounds/              Ogg runtime audio by category
ui/                  Briefings and UI images
repo/                README/showcase images
luts/                Runtime LUT files
```

Audio categories:

```text
sounds/ambience/
sounds/interaction/
sounds/machinery/
sounds/narration/
sounds/player/
sounds/ui/
```
